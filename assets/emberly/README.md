# Emberly — maskot assety

Sem dej obrázky maskota Emberly pro onboarding funnel a appku.

## Formát
- **SVG = ideál** (škáluje se ostře v každé velikosti). PNG `@2x` + `@3x` taky OK.
- Transparentní pozadí.

## Pojmenování (doporučené)
Stavy/emoce (pro onboarding kroky):
```
emberly-wave.svg        # mává — uvítání (krok 1)
emberly-happy.svg       # radost — obecné
emberly-think.svg       # přemýšlí — otázky
emberly-celebrate.svg   # oslava — „plán hotový" (krok 16)
emberly-cheer.svg       # povzbuzení — pledge (krok 14)
```

Evoluce tierů (krok 9 — Emberly roste Jiskra → Legendární):
```
emberly-tier-1-spark.svg
emberly-tier-2-flame.svg
emberly-tier-3-blaze.svg
emberly-tier-4-inferno.svg
emberly-tier-5-legendary.svg
```

## Poznámky
- **Neblokuje to** — když máš zatím jen jednu pózu, dej ji jako `emberly-happy.svg`;
  prompt ji použije všude a stavy doplníš později.
- Až přidáš/přejmenuješ, dej vědět — prompt pro Claude Code na funnel s těmito názvy počítá.
